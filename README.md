# GM300-AMCS 自动化

当前先按 `GM700` 的风格落了一版 AMCS 接口自动化骨架，采用：

- `pytest`
- `requests.Session`
- `allure`
- `yaml` 配置化环境与账号

## 目录

- `config/`：环境地址、接口路径、测试账号
- `common/`：通用请求工具
- `api/`：接口封装
- `testcase/`：测试用例

- 视频监控

- 预置位摄像机列表查询

- 巡检管理
- 巡检卡片列表
- 巡检计划列表

- 报警事件
- 报警记录列表查询

- 历史记录
- 联动历史分页查询

- 基础数据 / RDAC
- 站点列表查询
- 站点点位页面查询
- 站点点位 JSON 查询

- 系统配置 / GIS
- 二维地图属性查询

- GIS 全局配置查询

- 系统接口

- 时间戳接口登录态校验
- 系统健康检查接口

## 运行

```bash
pip install -r requirements.txt
pytest
```

生成 Allure 报告：

```bash
python run.py
```
